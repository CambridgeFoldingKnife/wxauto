# 健衡学园 生图风格锁（image-style-lock）

> 所有内文插图与封面，在生成提示词时**必须**注入以下风格锁（style-lock），保证图片与账号视觉一致。
> 核心：**扁平插画 · 医疗科普感 · 品牌青绿**。

---

## 一、三段式提示词模板（中文可直传即梦/通义万相）

```
【画面主体】<由 IMG/COVER 标记里的内容描述提供>

【风格统一锁——不许改】
扁平矢量插画风格，医疗健康科普质感，干净柔和，简洁现代；
主色调为青绿色（#32afaf），辅以奶白、浅蓝、浅灰等低饱和色系，少量金色点缀；
场景写实、人物为简化扁平风格（不追求真实五官细节）、构图留白充足；
无文字、无水印、无边框、无杂乱背景。

【构图/画幅】横构图，主体居中或略偏左；留白 40% 以上。
```

> 即梦/万相可直接理解中文。若切换英文模型，按下表翻译。

| 中文 | English |
| --- | --- |
| 扁平矢量插画 | flat vector illustration |
| 医疗健康科普质感 | medical-health science illustration, clean and soft |
| 主色青绿 #32afaf | primary teal color #32afaf |
| 低饱和色系 | low-saturation palette with off-white, light blue, light gray |
| 简化扁平人物 | simplified flat characters, no realistic facial detail |
| 留白充足 | generous negative space |
| 无文字无水印 | no text, no watermark |

## 二、按内容类型给的"画面主体"写作指引

| 章节内容 | 画面主体写法建议 |
| --- | --- |
| 概念定义（物理治疗是什么） | 一位康复师指导患者做抬臂训练的扁平插画场景 |
| 症状/后遗症（心慌气短） | 表现"患者爬楼喘息"的示意场景，避免直接画人痛苦表情 |
| 治疗手段（手法/运动疗法） | 治疗师双手在患者肩部做手法松解的画面 |
| 工具/器材（弹力带/训练床） | 弹力带拉伸动作特写、普拉提核心床等器材插画 |
| 对比（临床 vs 物理治疗） | 左右分屏对比图（一侧手术刀，一侧运动疗法） |
| 数据/证据（降低20%） | 简洁信息图风格：柱状图/百分比（可含少量数字，数字用青绿） |
| 课程/培训 | 教室授课场景、讲师示范、学员实操的扁平插画 |
| 人物致敬 | 扁平风格的康复师群像、剪影（不画真实个人肖像） |

---

## 三、画幅规格（脚本自动处理，写作不用管）

| 用途 | 比例 | 说明 |
| --- | --- | --- |
| 内文插图 | **3:2**（或 16:9） | 通栏横图，符合正文排版 |
| 封面 | **2.35:1** | 公众号文章封面主图标准 |

---

## 四、红线

1. 不生图时在图上直接写大段文字（除非信息图模式）；
2. 不出现真实知名人物肖像（致敬篇用剪影/群像）；
3. 不用高饱和度撞色，尊重品牌青绿主色；
4. 医疗画面必须体现"专业、正向"，避免病痛恐怖化表达。
