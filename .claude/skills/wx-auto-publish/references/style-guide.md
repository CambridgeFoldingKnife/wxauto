### Markdown 层级 ↔ 视觉样式映射

| Markdown | 视觉表现 | 使用场景 |
| --- | --- | --- |
| `#`（仅 frontmatter 用 title 字段） | 微信文章标题（编辑区展示，不进正文） | 标题即文章标题 |
| `##` | **青绿底白字长条**（药丸标题） | 一级章节：01 物理治疗是什么 |
| `###` | **奶黄胶囊卡**（青绿边+青绿字） | 二级板块：三个关键特征 / 课程简介 |
| `####` | **左侧青绿竖线 + 青绿加粗字** | 三级要点：心肺康复干预 / 第一步… |
| `**文字**` | 青绿加粗强调（金句感） | 关键词、结论句 |
| `>` | **奶黄卡片**（左边青绿粗线） | 名家语录、重要提醒、品牌尾注 |
| `---` | 半透青绿居中横线 | 章节间分隔 |
| `\| 表格 \|` | 表头浅蓝底+边框 | 对比表（临床 vs 物理治疗） |
| `![配图](imgs/xx.png)` | 通栏图、无圆角、居中 | 正文配图 |

### 正文排版硬性要求

- 正文字号 15px、行高 2em、两端对齐（主题已固化，写作时不用管）
- **段落短小**：每段 2~4 行，单段超过 5 行必须拆段
- 关键词、结论句用 `**加粗**`（自动变青绿）；不要在文中用 `#` 大标题（会与正文冲突）
- 列表用 `1、xxx` `2、xxx` 的**手写编号**（前面加 `**1、**`），比原生列表更像人工排版；要用原生列表也可以，但每项要短

## 二、文风规范

### 账号定位
**专注康复教育，推动专业前行**。读者：物理治疗师、康复师、运动康复从业者、慢病/术后患者家属。
语气：**专业、克制、有温度**。不浮夸、不标题党、不堆砌营销词；用数据、定义、金句建立专业感。

### 文本特征（从 5 篇实测）
- 用「」或引号强调概念（`"物理治疗"`、`「触诊感知弱」`）
- 喜爱**排比金句**收束章节，如：
  > 临床让你活着，中医让你舒服，物理治疗让你能动、能生活、能长久健康。
- 关键术语首次出现给括注：`物理治疗（Physiotherapy / Physical Therapy）`
- 数字、剂量、比例要具体：`全因死亡率降低约20%`、`200元押金`
- 结尾落点：致敬/祝福/行动号召（就诊建议）三选一 + 品牌尾注

### 两种文章样板（必须严格按结构走）

#### A. 科普型（世界物理治疗日等长科普）

- 分点论述

致敬/行动号召段落
---
> 健衡学园 ｜ 专注康复教育，推动专业前行
```

```
